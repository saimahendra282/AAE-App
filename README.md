# Advanced Alarm App (AAE)

> *This project is fully vibe coded using AI Studio. For now, I don't intend to share the codebase of it.*

## What Is This App For?

We all already have a default Clock app on our phones—but does it automatically ring every single year at that exact moment to remind you of important dates without manual re-adding? Mine didn't. So I decided to build a personal solution that turns everyday reminder problems into dedicated alarm features.

Beyond standard date-and-time alarms, **AAE** combines location arrival alerts, yearly auto-repeating special events, safe local folder backups, and seamless GitHub auto-updates in one place.

## App Features

- **Location Arrival Alarms:** Rings an alarm automatically when you approach a saved place or chosen destination within your configured arrival distance (in meters / km).
- **Yearly Special Event Alarms:** Save birthdays, anniversaries, or annual milestones once with **Repeat every year**—the app highlights them in sparkling gold under **Special Events** across Clock and Calendar views and automatically rolls them over to the next year after ringing.
- **Scheduled Date & Time Alarms:** Create one-time or calendar-planned alarms with 12-hour time picking, custom alarm ringtones, notes, snooze support, and Month / Week / Day / List calendar views.
- **Dedicated Backup Folder Sync:** Connect a folder on your device so your events, yearly alarms, saved places, and settings stay safely backed up (and easily restored on reinstall) with one-tap Export and Merge Import.
- **Built-in Auto-Updater:** Checks `version.txt` in this repository on launch (or manually via the reload button in Settings) and lets you download and install the latest APK directly.

## Try It Out

Download the latest `.apk` (`AAE-latest.apk`) from this repository and install it on your Android device. Future releases can then be updated directly from inside the app!
